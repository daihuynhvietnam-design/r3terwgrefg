# THE LEGION HOTEL

Website giới thiệu 3 khách sạn gia đình:
- Khách Sạn Thanh Bình - Bến Tre
- Khách Sạn Hoàng Yến - Thanh Hòa, Cai Lậy
- Khách Sạn Hoàng Yến - Mỹ Thạnh Hưng, Đồng Tháp

## Chạy website
Mở `index.html` bằng Chrome/Edge.

## Đặc điểm
- Không có đặt phòng online.
- Liên hệ trực tiếp qua điện thoại, Zalo, Facebook.
- Bến Tre: phòng đơn 200.000đ, phòng đôi 300.000đ.
- Cai Lậy: chỉ phòng đơn 200.000đ.
- Đồng Tháp: phòng đơn 200.000đ, phòng đôi 300.000đ.
- Dark/Light mode.
- Responsive.
- Animation và gallery.
- Ảnh đang dùng các URL bạn đã cung cấp.

Lưu ý: Một số ảnh từ Facebook/Agoda/Booking có thể thay đổi URL hoặc chặn hotlink. Nếu ảnh không hiển thị khi deploy, hãy tải ảnh về thư mục `images/` rồi thay URL bằng đường dẫn local.
